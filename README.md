# Le Tre Celle

App della pescheria: conteggi di cella, banco e surgelati, DDT e venduto, ordine del giorno.

- Si apre da **https://letrecelle.github.io** e si installa sul telefono (Chrome: "Installa app" / Safari: "Aggiungi alla schermata Home").
- I dati stanno nel progetto Firebase `le-tre-celle` e sono visibili solo a chi entra con l'account del negozio.
- `firestore.rules` è una copia delle regole del database (quelle vere si cambiano dalla console Firebase).
